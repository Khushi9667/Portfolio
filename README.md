# Khushi Jain | Portfolio

Welcome to my digital space. This repository hosts the source code for my professional portfolio—a lightweight, interactive web application engineered to showcase my background in Computer Science, full-stack systems, deep learning research, and creative design.

---

## Key Features

* **Interactive 3D Elements:** Implements smooth, performance-optimized 3D assets utilizing Three.js and GSAP for fluid, scroll-triggered animations.
* **Modern UI/UX:** Built with a sophisticated glassmorphism visual style, custom holographic skill matrices, and a cohesive warm palette.
* **Responsive Architecture:** Fully optimized for seamless cross-device rendering, from mobile screens to high-resolution desktop monitors.
* **Background Log Streamer:** Integration of dynamic background triggers to mirror live build processes or pipeline updates seamlessly.
